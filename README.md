# 시간표 리그

말로 조건을 쓰면 충돌 없는 시간표를 짜 주고, 대표 시간표를 점수로 심사해 학과끼리 겨루는 인천대 시간표 학과 대항전.

- 서비스: https://vibe-contest-brown.vercel.app
- 출품: 바이브코딩 대회 「AI로 다시 쓰는 대학생활」 · 팀 AI Intelligence · 2026-11-06
- 학교의 공식 시스템이 아닌 대회 출품작

## 주요 기능

| 기능 | 내용 |
|---|---|
| 말로 하는 시간표 편성 | 「월요일 쉬고 1교시 싫어」 같은 문장을 조건으로 변환, 충돌 없는 후보 계산 |
| 시간표 심사 | 공강, 점심, 학점, 1교시·야간, 우주 공강, 연강, 동선 7개 항목 100점 만점 |
| AI 칭호·평론 | 계산된 점수표를 근거로 행정 문서 말투의 평가 |
| 학과 대항전 | 대표 시간표 점수의 학과 평균으로 순위 산정 |
| 공유와 궁합 | 공유 링크로 결과 공개, 친구와 겹치는 공강·점심·건물과 AI 해설 제공 |

## 코드와 AI의 역할 분담

틀리면 안 되는 계산은 코드, 말을 이해하고 설명하는 일은 AI 담당.

| 코드 | AI |
|---|---|
| 분반 조합 탐색, 충돌 검사, 실패 원인 진단 | 자유 문장을 조건으로 변환 |
| 점수, 등급, 순위 계산 (서버에서 확정) | 조건 대비 예상 만족도 평가 (순위 미반영) |
| 궁합의 겹치는 정보 계산 | 칭호, 평론, 궁합 해설 작성 |

AI 호출 순서: Gemini 3.5 Flash Lite → Gemini 3.1 Flash Lite → Groq. 모두 실패해도 코드 계산과 고정 문구로 계속 동작.

## 구조

```text
api/       Vercel 서버 함수: AI 중계, 대표 등록, 순위, 공유, 궁합
lib/       서버 공용 코드: Firestore, 순위 계산, 공유 공개 범위
prompts/   서비스 안에서 AI에게 주는 지시문
public/    화면, 강의 자료
  lib/     화면과 서버가 함께 쓰는 계산: 시간표 탐색, 점수, 궁합
scripts/   강의 자료 변환, 로컬 서버, 화면 시험
tests/     자동 테스트
설계/      유저 플로우, 진행 기록
자료/      발표용 자료
```

## 실행

Node 20 이상 필요. 외부 패키지 설치 불필요.

```powershell
Copy-Item .env.example .env.local
node scripts/dev-server.mjs
npm test
```

AI와 저장 기능을 쓰려면 `.env.local`에 키 입력 필요. 키가 없으면 AI는 고정 문구로 대체.

## 보안과 개인정보

- API 키는 서버 환경 변수에만 보관
- 점수는 서버가 다시 계산, 브라우저가 보낸 점수 미사용
- 데이터베이스는 서버 전용 계정만 읽기·쓰기 가능
- 공개 정보는 닉네임, 학과, 칭호, 평론, 등급, 점수로 제한
- 강의 자료에서 교수 이름 제외

# 시간표 서비스 워크플로우

작성: 2026-11-06(금) 11:13 KST · 상태: 임시 확정 아이디어 · 관리자 원안 6단계의 세분화본

## 한 줄 정의

학생이 말로 조건을 입력해 시간표를 짜고, 대표 시간표 점수로 누가 좋은 시간표를 짰는지 겨루는 인천대 학과 대항전 웹.

## 역할 원칙

- AI: 말 → 조건 변환, 추천 이유, 실패 대안 설명, 칭호와 평론
- 코드: 시간표 계산, 충돌 검사, 점수 계산, 랭킹 산출
- AI 실패 시: 체크박스 입력과 고정 문구로 진행 유지

## 학과 대항전 규칙 초안

- 학과 점수: 등록자 평균 점수
- 순위 진입: 등록 3명 이상
- 동점: 등록 인원이 많은 학과 우선
- 공개 정보: 닉네임, 학과, 점수, 등급 · 시간표 전체 공개 여부는 사용자 선택
- 위험: 학과별 강의 구조 차이로 유불리 발생 가능 · 시연 뒤 보정 후보

## 졸업 연계 (축소, 시간 남을 때만)

UNIAI가 졸업 요건 현황을 공식 제공하므로 현황판은 미제작. 교육과정 자료 확보 학과에 한해 남은 필수 과목을 3번 화면 추천에 반영. 복수전공·부전공 제외.

## 구현 순서

1. 자료 파싱과 시간표 계산, 단위 테스트
2. 조건 입력 → AI 변환 → 3안 생성 → 결과 비교 (로그인 없이도 동작)
3. 점수, 등급 연출, AI 칭호·평론
4. Firebase 로그인, 대표 저장, 내 현황, 학과 대항전
5. 직접 수정
6. 공유 카드
7. 경쟁률, 졸업 연계

13:30 개발 동결 기준 5~7번은 시간 부족 시 포기 대상. 13:15에 시연 가능한 상태 필요.
